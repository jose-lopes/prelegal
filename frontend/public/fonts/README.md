# Bundled Noto Sans fonts

Copyright The Noto Project Authors. Licensed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

These unmodified fonts provide Latin, Greek and Cyrillic characters, including accented names. CJK and other scripts outside their coverage are not supported by this prototype. No external font requests are made at runtime.
